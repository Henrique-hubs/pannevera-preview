# Prévia da Pannevera para GitHub Pages

Esta é uma cópia estática para apresentar o visual do site. O catálogo começa vazio e não é sincronizado com o site hospedado nem com o painel de administração. Não é uma cópia de produção e não aceita cadastro de produtos.

Para publicar, crie um repositório no GitHub, adicione estes arquivos à raiz e habilite GitHub Pages em Settings → Pages, escolhendo Deploy from a branch, a branch principal e a pasta `/ (root)`. O endereço será informado pelo GitHub na página de configurações. As imagens e os links usam caminhos relativos, para funcionar também em repositórios publicados em subpastas.

Não inclua credenciais, informações de clientes ou dados sensíveis no repositório, especialmente se ele for público.
